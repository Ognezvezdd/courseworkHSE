# Mafia Python API

Python-часть Mafia отвечает за модели данных, FastAPI endpoints и логику выбора действий агентов. Игровой цикл Mafia в текущей версии находится в C++ (`cpp/src/mafia_game.*`), а Python-сервис вызывается C++ прокси-агентами.

## Основные компоненты (в `src/`)

### `models.py`
Содержит Pydantic-модели, соответствующие структурам данных C++:
- `GameState`: Полное состояние игры.
- `PlayerState`: Информация об игроке.
- `ChatMessage`: Сообщение в чате.
- `AgentAction`: Действие агента (убийство, проверка, лечение, голос и т.д.).

### `strategies/`
Содержит логику для конкретных ролей:
- `base_strategy.py`: Интерфейс `RoleStrategy`.
- `random_strategies.py`: Случайные ходы для всех ролей.

### `agents/unified_agents.py`
Содержит базового унифицированного агента и случайного агента, способного играть за любую роль:
- `RandomAgent`: Использует `Random*Strategy` для любой выпавшей роли.

### `agents/llm_gemma3_agent.py`
Содержит `LLMAgent`, который использует локальную языковую модель через Ollama для анализа состояния игры, блефа, голосований и принятия решений.

### `agent_factory.py`
Фабрика создает агентов по типу интеллекта (`RANDOM`, `LLM`), а не по роли. Роль передается агенту в момент принятия решения.

### `api.py`
FastAPI роутер, реализующий эндпоинты:
- `POST /mafia/agent_action`: Запрос действия.
- `POST /mafia/agent_chat`: Запрос текстового сообщения.

## Архитектура: Stateless vs Stateful

Агенты реализованы как **Stateless** компоненты. Это значит, что они принимают `GameState`, вычисляют действие и не хранят состояние сессии.

**LLM-агенты** получают историю чата, голосований, список выбывших игроков и личную информацию через промпт. Имена игроков анонимизируются в формате `Player_N`, чтобы не раскрывать роли через исходные имена.

## Тестирование

Запуск тестов из корня `python/`:
```bash
cd python
python3 -m pytest games/mafia/src/tests -v
```

Запуск конкретных тестов:
```bash
python3 -m pytest games/mafia/src/tests/test_agents.py -v
python3 -m pytest games/mafia/src/tests/test_llm_agent.py -v
```

Текущий набор Mafia-тестов входит в общий Python-прогон проекта.

## Интеграция с C++

Для интеграции используется HTTP API. C++ ядро (движок игры) отправляет текущее состояние в JSON, а Python-сервис возвращает выбранное действие.
Модели данных в `models.py` синхронизированы с C++ структурами.
