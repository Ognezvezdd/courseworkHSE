
# Мафия на Python

Часть курсовой, посвященная логике агентов для игры "Мафия", интегрированной с C++ ядром.

## Основные компоненты

### `mafia/models.py`
Содержит Pydantic-модели, соответствующие структурам данных C++ (GameState, PlayerState, ChatMessage, AgentAction).


### `mafia/strategies/`
Содержит логику для конкретных ролей:
- `base_strategy.py`: Интерфейс `RoleStrategy`.
- `random_strategies.py`: Случайные стратегии для всех ролей.
- `rl_strategy.py`: Заготовка для RL (Reinforcement Learning).

### `mafia/agents/unified_agents.py`
Содержит унифицированных агентов, способных играть за любую роль:
- `RandomAgent`: Использует `Random*Strategy` для любой выпавшей роли.
- `RLAgent`: Использует RL стратегии, собирает опыт для обучения.

### `mafia/agent_factory.py`
Фабрика теперь создает агентов по типу интеллекта (`RANDOM`, `RL`, `LLM`...), а не по роли.

### Архитектура State & Stateless
Агенты реализованы как **Stateless** компоненты относительно игрового сеанса API.
Это значит, что сервер C++ присылает полный слепок состояния (`GameState`), агент принимает решение и забывает всё до следующего запроса.

**Почему так сделано:**
1. Легко масштабировать (можно запускать 1000 игр параллельно).
2. Проще отлаживать (результат зависит только от входных данных).

**Как сделать Stateful (для RL/LLM с памятью):**
1. Добавить `session_id` в запросы API.
2. В Python использовать Redis или словарь `sessions = {}` для хранения контекста (истории сообщений, скрытых переменных RL агента).
3. В `BaseAgent.decide_action` подгружать контекст по `session_id`.

## Тесты

Тесты находятся в `mafia/tests/`. Запуск:
```bash
pytest python/mafia/tests/
```

## Интеграция

Для интеграции с C++ используется HTTP API (см. `api.py`). C++ отправляет состояние игры, Python возвращает действие агента.
