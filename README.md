# Курсовая работа ПИ 2 курс
## Платформа симуляции конкурентного взаимодействия AI-агентов (Competitive Multi-Agent Simulation Platform)
### Авторы: Капогузов М. Е, Дудкина А. Э.

Платформа симуляции конкурентного взаимодействия AI-агентов.  
Ядро интерфейса написано на **C++**, логика агентов и игр — на **Python**, управление — через **Telegram-бота**.

## Основная идея

- Запуск матчей между агентами с разными стратегиями
- Выбор игры и агента пользователем
- Виртуальные ставки (баллы) на исход матча
- Просмотр хода игры и результатов через Telegram
- Пользователь может "болеть" за выбранного агента

---

## Структура проекта

Проект разделен на два независимых модуля:

- **`cpp/`** — Клиентская часть (Telegram-бот на C++), управляющая взаимодействием с пользователем.
- **`python/`** — Серверная часть (AI Platform), отвечающая за логику игр, агентов и визуализацию.

---

## C++ Часть (Telegram Bot)

Реализует интерфейс пользователя через Telegram. Основные возможности:
- Регистрация пользователей и ведение счета (виртуальная валюта).
- Меню выбора агентов и создание матчей.
- Прием ставок на результат игры.
- Отображение хода игры (получение лога от Python-части).

**Технологии:** C++17, `libcurl` (для запросов), `nlohmann/json` (JSON парсинг).

**Ключевые компоненты:**
- `TelegramBot`: Обработка Long Polling обновлений и отправка сообщений.
- `GameManager`: Управление запуском игр (взаимодействие с Python).
- `Config`: Загрузка конфигурации (токен бота, пути).

---

## Python Часть (AI Core)

Реализует игровую логику и интеллект агентов.

**Технологии:** Python 3.11+, FastAPI, Matplotlib (визуализация).

**Возможности:**
1. **Агенты**:
   - `RandomAgent`: Делает случайные ходы.
   - `HeuristicAgent`: Использует жестко заданные правила (победа, блокировка, центр).
   - `QLearningAgent`: Обучаемый агент (Reinforcement Learning).
2. **Игры**: Сейчас реализованы **Крестики-нолики 5x5** (победа — 4 в ряд).
3. **Визуализация**: Генерация изображений поля для отправки пользователю.
4. **REST API**: Сервер на FastAPI для интеграции.

## API и Взаимодействие (Саша, тебе вот это нужно)

Взаимодействие между C++ и Python частями может происходить двумя способами: CLI (легаси) и HTTP API (рекомендуется).

### REST API

Python часть запускается как микросервис (в Docker или локально):
```bash
uvicorn api:app --host 0.0.0.0 --port 8000
```

#### Эндпоинты:

1. **`POST /game/play`** — Запуск игры.
   - **Request**:
     ```json
     {
       "agent_x": "heuristic",
       "agent_o": "random",
       "seed": 42
     }
     ```
   - **Response**: Возвращает JSON с полным логом игры (`slides`), количеством шагов и победителем.

2. **`POST /train`** — Обучение агента.
   - **Request**: `{"agent_type": "qlearning", "episodes": 1000}`
   - **Response**: Статистика обучения.

3. **`GET /agents`** — Список доступных типов агентов.

#### Интеграция в C++:
Вместо вызова `system()` или `popen()`, C++ код может использовать HTTP-клиент (например, `libcurl` или `cpr`) для отправки POST-запросов на порт 8000. Это изолирует части системы и упрощает деплой в контейнерах.

### Docker
Весь Python-бэкенд упакован в Docker container:

docker build -t ai-platform .
docker run -p 8000:8000 ai-platform
